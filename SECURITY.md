# セキュリティポリシー / Security Policy

## サポートされているバージョン / Supported Versions

| バージョン / Version | サポート状況 / Supported |
|---------------------|--------------------------|
| 最新 (main ブランチ) | ✅ |
| 古いバージョン       | ❌ |

Only the latest version is actively supported.

## 脆弱性の報告方法 / Reporting a Vulnerability

### 🇯🇵 日本語の場合:

脆弱性やセキュリティ上の問題を発見した場合は、**公開 Issue ではなく、以下の手順で報告してください**。

- メールでご連絡ください:  
  `akiy2009_dev@outlook.jp`

- 報告内容に含めてほしい情報:
  - 問題の詳細な説明
  - 再現手順（あれば）
  - 影響の範囲や緊急度の見積もり

できるだけ早く調査・対応いたします。対応が完了するまで情報を公開しないようご協力をお願いいたします。

---

### 🇺🇸 In English:

If you discover a security vulnerability, **please do not report it via a public issue**. Instead, report it privately by email:

- Contact:  
  `akiy2009_dev@outlook.jp`

- Please include:
  - A detailed description of the issue
  - Steps to reproduce (if available)
  - Your estimate of the impact/severity

We will investigate and respond as quickly as possible. Please keep the issue confidential until we’ve addressed it.
