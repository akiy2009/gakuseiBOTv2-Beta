# リマインダー機能

## 概要

`/remind` コマンドで自分用の予定を登録し、指定時刻に Bot から DM を受け取れます。日時の入力と表示は日本時間（JST）です。予定は `USER_DATA_DB`（未設定時は `data/user_data.sqlite3`）の SQLite データベースに保存されます。

## コマンド

| コマンド | 説明 |
| --- | --- |
| `/remind add` | 日時と内容を指定して登録 |
| `/remind list` | 自分の未完了リマインダーを表示 |
| `/remind cancel` | 登録を取り消す |
| `/remind done` | 完了扱いにする |
| `/remind snooze` | 1〜10080分延期する |

登録例:

```text
/remind add when:2026-11-12 18:30 message:研究発表の資料を確認する
```

日時は `YYYY-MM-DD HH:MM` 形式で入力します。過去の日時と現在から1年を超える日時は登録できません。1ユーザーにつき未完了の予定は最大100件です。

## 配信・再起動への対応

- Bot 起動中は30秒間隔で期限到来を確認します。
- 予定はSQLiteへ保存されるため、Bot再起動後も未完了の予定を復元します。
- 配信処理は短時間のリースを取得してから実行し、プロセス停止で残ったリースは期限切れ後に再処理します。
- 一時的なDiscord APIエラーは待ち時間を延ばしながら再試行します。
- DMを受け取れないユーザーへの予定は `failed` 状態になります。DMを受信できる設定に変更した後、必要に応じて新しい予定を登録してください。
- 通知本文中のメンションは無効化します。

## 配信保証について

配信方式は at-least-once（少なくとも1回を目指す方式）です。DiscordがDMを受理した直後、DBへ送信済み状態を書き込む前にプロセスが停止した場合、再起動後に同じ通知が再送される可能性があります。外部サービスへの送信とSQLite更新を単一トランザクションにできないため、完全な重複ゼロは保証しません。

通知はBotからのDMで届きます。Discordのプライバシー設定でサーバーメンバーからのDMを受信できるようにしてください。
