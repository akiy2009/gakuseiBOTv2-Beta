# 変更・レビューのルール

- Bot token、HSS API token、SSH 鍵、実在する利用者データをコミットしないでください。
- 依存関係を追加する場合は、必須機能と任意機能を分離できるか検討し、用途と対応 Python バージョンをドキュメントに記載します。
- 外部プロジェクトのソースコードをコピーする前に、利用条件とライセンスを確認します。外部コードを依存関係として使う場合は、upstream とライセンス情報を明示します。
- 外部 API に接続するテストには秘密情報を要求せず、モックによるテストと実環境での確認を分けます。
- 変更後は依存関係チェック、構文チェック、pytest、ドキュメントビルドを実行し、PR で結果を共有します。
