# 環境変数と設定

設定値はプロセス環境変数またはリポジトリ直下の `.env` から読み込みます。実際の環境変数は `.env` の値より優先されます。

## 実行環境

Bot 本体・任意の HSS 時間割連携・テスト・ドキュメント生成は Python 3.12.x に統一しています。ローカル環境では Python 3.12 で作成した仮想環境を使用してください。Dockerfile も Python 3.12 ベースです。

## Bot 本体

| 変数 | 必須 | 既定値 | 用途 |
| --- | --- | --- | --- |
| `DISCORD_TOKEN` | はい | なし | Discord Bot token。未設定なら起動時に終了します。 |
| `PREFIX` | いいえ | `/` | prefix command の接頭辞。空欄は既定値に戻ります。 |
| `DEVELOPER_ID` | いいえ | 空欄 | 開発者向け機能が参照する Discord ユーザー ID。 |
| `REPORT_CHANNEL_ID` | いいえ | 空欄 | 起動ログの送信先チャンネル ID。未設定なら自動送信しません。 |
| `FEEDBACK_CHANNEL_ID` | いいえ | 空欄 | `/feedback` の送信先チャンネル ID。 |
| `HEAVY_THRESHOLD` | いいえ | `1.5` | Cog 読み込み時間の警告閾値（秒）。正の数値以外は既定値を使用します。 |
| `HEAVY_COGS_PATH` | いいえ | `data/heavy_cogs.json` | 読み込みをスキップする Cog 一覧を保存する JSON ファイル。 |

## ログ管理

ログは Python 標準の `logging` に統一し、時刻・レベル・logger 名・メッセージを同じ形式で出力します。標準出力/標準エラーに加え、既定では UTF-8 のローテーションファイルにも保存します。Docker Compose では `bot-logs` volume に保持します。

| 変数 | 必須 | 既定値 | 用途 |
| --- | --- | --- | --- |
| `LOG_LEVEL` | いいえ | `INFO` | ログレベル。例: `DEBUG`, `INFO`, `WARNING`, `ERROR`, `CRITICAL`。 |
| `LOG_FILE` | いいえ | `logs/gakuseibot.log` | ログファイルのパス。空欄にするとファイル出力を無効化し、コンソール出力のみになります。 |
| `LOG_MAX_BYTES` | いいえ | `5242880` | 1ファイルあたりの最大サイズ（bytes）。正の整数を指定します。 |
| `LOG_BACKUP_COUNT` | いいえ | `5` | 保持するローテーション済みファイル数。0 はバックアップを保持しません。 |

ログファイルはサイズ上限に達するとローテーションします。メモリ上の起動ログバッファは直近 200 件に制限し、Discord の起動レポートが無制限に増えないようにします。通常の利用者向け応答には内部例外の詳細や秘密情報を含めず、予期しないエラーには問い合わせ用の処理 ID を付けます。

## HSS 時間割連携（任意）

以下の 4 項目を**すべて**設定した場合だけ、HSS クライアントの初期化を試みます。

| 変数 | 必須（HSS を使う場合） | 用途 |
| --- | --- | --- |
| `INSTALL_HSS` | いいえ（Docker のみ） | `true` にすると Docker イメージのビルド時に HSS.py を追加インストールします。既定値は `false`。 |
| `HSS_API_TOKEN` | はい | HSS API application token。秘密情報として管理します。 |
| `HSS_SCHOOL_ID` | はい | 表示対象の学校 ID（正の整数）。 |
| `HSS_GRADE` | はい | 表示対象の学年（正の整数）。 |
| `HSS_CLASS` | はい | 表示対象のクラス番号（正の整数）。 |

HSS の追加依存関係は `requirements-hss.txt` で別管理します。Bot 本体と同様に Python 3.12.x を使用します。HSS を設定しなくても Bot 本体は起動し、`/timetable` は未設定メッセージを返します。

## 秘密情報の取り扱い

- `.env`、token、API key をコミットしないでください。例示ファイルにはプレースホルダーだけを記載します。
- token をログや Discord メッセージに出さないでください。公開してしまった token は無効化し、新しいものを発行してください。
- デプロイ先では GitHub Actions の Secrets とサーバー上の `.env` を使い分けます。環境変数の値そのものをドキュメントや CI ログに出力しないでください。
